# 钢球8.0 使用说明

本目录为 2026 年全国大学生电子设计竞赛 H 题车载平衡滚球系统的非 YOLO 视觉版本。

该版本不依赖 `.mud` 模型文件，主要通过传统视觉方法完成钢球识别，并输出钢球相对摆杆中心的位置和速度。

## 文件说明

- `main.py`：主程序入口，负责摄像头、视觉识别、UART、图传和本地显示的调度。
- `config.py`：集中配置文件，包含功能开关、相机参数、摆杆标定、传统视觉阈值、卡尔曼参数和 UART 参数。
- `classic_ball_module.py`：传统视觉钢球识别模块。
- `ball_module.py`：坐标换算、状态定义、卡尔曼跟踪和画面叠加相关功能。
- `communication.py`：UART0 通信与 CRC 校验。
- `video_stream.py`：浏览器图传服务。
- `receiver_page.py`：浏览器端接收、录制、回放和下载页面。
- `app.yaml`：MaixCAM 应用配置文件。
- `app.png`：MaixCAM 应用图标。

## 使用步骤

1. 将本目录中的所有文件上传到 MaixCAM 应用目录。
2. 打开 `config.py`，根据现场安装情况修改摆杆标定参数：

```python
ROD_LEFT_POINT = (20, 120)
ROD_RIGHT_POINT = (300, 120)
ROD_LENGTH_MM = 250.0
BALL_DIAMETER_MM = 10.0
```

3. 根据需要开启或关闭功能：

```python
ENABLE_UART = True
ENABLE_STREAM = True
ENABLE_DISPLAY = True
DEBUG_MODE = True
```

4. 运行 `main.py`。
5. 启动后确认摄像头画面稳定，并检查钢球识别框是否跟随钢球移动。
6. 若使用 UART，请确认 MaixCAM 与主控共地，并按下面方式接线。
7. 若使用图传，请在同一网络下打开程序输出的 HTTP 地址查看实时画面。

## UART0 接线

```text
MaixCAM A16 / UART0_TX  -> 主控 RX
MaixCAM A17 / UART0_RX  <- 主控 TX
MaixCAM GND             -- 主控 GND
```

默认串口参数：

```text
设备：/dev/ttyS0
波特率：115200
数据格式：8N1
```

## UART 数据格式

视觉端输出格式：

```text
$VIS,status,x_mm,v_mm_s,seq,crc#
```

字段说明：

- `status=0`：丢球，`x_mm` 和 `v_mm_s` 为 0。
- `status=1`：当前帧测量结果。
- `status=2`：短时预测结果。
- `x_mm`：钢球相对摆杆中心的位置，单位 mm。
- `v_mm_s`：钢球速度，单位 mm/s。
- `seq`：循环序号。
- `crc`：CRC-8/ATM 校验。

## 标定建议

固定摄像头和摆杆后，先确认整根摆杆都在 320x240 画面内。

然后依次调整：

1. `ROD_LEFT_POINT`
2. `ROD_RIGHT_POINT`
3. `POSITION_CALIBRATION`
4. `CLASSIC_ROD_ROI`

建议先让钢球分别停在左端、中点和右端，核对输出位置是否符合实际方向和距离。

## 注意事项

- 本版本不需要 YOLO 模型文件。
- 改变摄像头位置、分辨率或摆杆安装位置后，需要重新标定。
- 比赛时建议只开启必要输出，减少 MaixCAM 负载。
- 若画面中高光、背景反光较强，需要重新调整 `config.py` 中的传统视觉阈值。
