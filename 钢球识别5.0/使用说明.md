# 钢球识别5.0 使用说明

本目录为 2026 年全国大学生电子设计竞赛 H 题车载平衡滚球系统的 YOLO 视觉版本。

该版本支持 YOLOv5 模型检测钢球位置，同时保留传统视觉备用路径。程序会输出钢球相对摆杆中心的位置和速度，可用于主控闭环控制。

## 文件说明

- `main.py`：主程序入口，负责摄像头、视觉识别、UART、图传和本地显示的调度。
- `config.py`：集中配置文件，包含功能开关、相机参数、YOLO 模型路径、摆杆标定、卡尔曼参数和 UART 参数。
- `ball_module.py`：YOLO 检测、坐标换算、卡尔曼跟踪和画面叠加相关功能。
- `classic_ball_module.py`：传统视觉备用识别模块。
- `communication.py`：UART0 通信与 CRC 校验。
- `video_stream.py`：浏览器图传服务。
- `receiver_page.py`：浏览器端接收、录制、回放和下载页面。
- `app.yaml`：MaixCAM 应用配置文件。
- `app.png`：MaixCAM 应用图标。

## 使用步骤

1. 将本目录中的所有文件上传到 MaixCAM 应用目录。
2. 准备 YOLO 模型文件：

```text
model_310353.mud
```

3. 将模型文件放到应用目录，或放到 MaixCAM 的系统模型目录：

```text
/root/models/model_310353.mud
```

4. 打开 `config.py`，确认启用 YOLO：

```python
ENABLE_AI = True
```

如果 `ENABLE_AI = False`，程序会切换到传统视觉备用路径。

5. 根据现场安装情况修改摆杆标定参数：

```python
ROD_LEFT_POINT = (20, 120)
ROD_RIGHT_POINT = (300, 120)
ROD_LENGTH_MM = 250.0
BALL_DIAMETER_MM = 10.0
```

6. 根据需要开启或关闭功能：

```python
ENABLE_UART = False
ENABLE_STREAM = False
ENABLE_DISPLAY = True
DEBUG_MODE = False
```

7. 运行 `main.py`。
8. 启动后确认摄像头画面稳定，并检查 YOLO 检测框是否正确跟随钢球。
9. 若使用 UART，请确认 MaixCAM 与主控共地，并按下面方式接线。
10. 若使用图传，请在同一网络下打开程序输出的 HTTP 地址查看实时画面。

## YOLO 模型说明

默认模型路径在 `config.py` 中配置：

```python
MODEL_LOCAL_PATH = "model_310353.mud"
MODEL_SYSTEM_PATH = "/root/models/model_310353.mud"
CONFIDENCE_THRESHOLD = 0.5
IOU_THRESHOLD = 0.45
```

程序启动时会优先查找应用目录下的 `model_310353.mud`。

如果应用目录中没有模型文件，则继续查找：

```text
/root/models/model_310353.mud
```

如果两个位置都没有模型文件，启用 YOLO 时程序会报错。

## UART0 接线

```text
MaixCAM A16 / UART0_TX  -> 主控 RX
MaixCAM A17 / UART0_RX  <- 主控 TX
MaixCAM GND             -- 主控 GND
```

默认串口参数：

```text
设备：/dev/ttyS0
波特率：115200
数据格式：8N1
```

## UART 数据格式

视觉端输出格式：

```text
$VIS,status,x_mm,v_mm_s,seq,crc#
```

字段说明：

- `status=0`：丢球，`x_mm` 和 `v_mm_s` 为 0。
- `status=1`：当前帧 YOLO 测量结果。
- `status=2`：卡尔曼短时预测结果。
- `x_mm`：钢球相对摆杆中心的位置，单位 mm。
- `v_mm_s`：钢球速度，单位 mm/s。
- `seq`：循环序号。
- `crc`：CRC-8/ATM 校验。

## 标定建议

固定摄像头和摆杆后，先确认整根摆杆都在 320x240 画面内。

然后依次调整：

1. `ROD_LEFT_POINT`
2. `ROD_RIGHT_POINT`
3. `ROD_LENGTH_MM`
4. `BALL_DIAMETER_MM`

如果 YOLO 检测框正常，但输出坐标偏差较大，优先检查摆杆端点标定。

如果 YOLO 检测不稳定，可以适当调整：

```python
CONFIDENCE_THRESHOLD = 0.5
IOU_THRESHOLD = 0.45
```

## 注意事项

- 本版本需要 `model_310353.mud` 模型文件才能使用 YOLO。
- 如果不放模型文件，请将 `ENABLE_AI = False`，程序会走传统视觉备用路径。
- 改变摄像头位置、分辨率或摆杆安装位置后，需要重新标定。
- 比赛时建议只开启必要输出，减少 MaixCAM 负载。
- `DEBUG_MODE = True` 时会显示 YOLO 原始框，便于调试，但可能增加画面绘制负担。
