# Mzixcam-2026-H

2026 年全国大学生电子设计竞赛 H 题车载平衡滚球系统 MaixCAM 视觉代码。

本仓库包含两个比赛视觉版本：

- `钢球8.0/`：非 YOLO 版本，基于传统视觉方法识别钢球位置。
- `钢球识别5.0/`：YOLO 版本，支持 YOLOv5 模型检测，并保留经典视觉备用路径。

## 项目说明

代码运行平台为 MaixCAM，主要功能包括：

- 摄像头图像采集
- 钢球位置识别
- 坐标换算与卡尔曼短时预测
- UART0 串口输出视觉数据
- MaixCAM 本地屏幕显示
- 浏览器图传与录制页面
